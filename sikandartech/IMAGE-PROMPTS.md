# SikandarTech: photo prompts (one prompt per image)

Copy each prompt as it is. Save the image with the **exact file name** shown, in the folder shown, and send it back
(or put it in the folder and run `python3 catalog-src/build.py`). The website uses it automatically.

Every prompt already includes the style and the rules: no smartphones or mobile phones, no logos, no text, no people.

## D. Optional: any other product

Any catalogue product can get a photo: save it as `images/products/<product-id>.jpg` (1600 × 1600).
The product id is the product name in lowercase with dashes (e.g. `robot-dogs.jpg`); it also appears in the page
address when a product is opened (`products.html#robot-dogs`). Use the B prompts as a pattern.

## E. Community videos

Community (UGC) videos must be real customer content shared with permission, not generated. Add them in `ugc-data.js`.
